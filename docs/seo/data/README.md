# Verified demand dataset

`demand-monthly-2026-09-21.json` — US monthly Google search volume for 46 green-industry service
terms, pulled from the DataForSEO Google Ads endpoint on 2026-09-21. Each value is the mean of
that calendar month across the available years, so a single odd year cannot move a peak.

**This file is the only permitted source for seasonality claims.** Do not restate a number from
the 2026-08 magazine draft: three of its four headline figures did not survive re-verification
(see STRATEGY.md, 2026-09-21). Re-pull and re-check before publishing anything from it; search
demand moves, and a stale number published under Matt's byline is worse than no article.
